Схема

The map

Точки бегут по проводам так же, как события по шине ядра. Всё кроме «мозга» и Telegram работает локально.

Dots run along the wires the way events run over the core's bus. Everything except the “brain” and Telegram stays local.

ОболочкаShellElectron открывает два окна, запускает ядро и перезапускает его, если оно упало. Окнам нельзя уходить на чужие адреса.Electron opens two windows, starts the core and restarts it if it crashes. Windows can't
ЯдроCoreСервер слушает только 127.0.0.1 и проверяет Origin, так что сайты в браузере до него не достают. Окна получают события по WebSocket.The server listens on 127.0.0.1 only and checks Origin, so web pages can't reach it. Windows get events over WebSocket.
ГолосVoiceSilero VAD режет фразы, маленький Whisper ловит имя, второй распознаёт просьбу. Ответ говорит Silero (RU) или Kokoro (EN), губы двигаются в такт.Silero VAD splits phrases, a small Whisper listens for her name, another one hears the request. Silero (RU) or Kokoro (EN) speaks the reply with lip-sync.
ПлагиныPluginsПапка plugins/<имя>: plugin.py добавляет инструменты, panel.html — свою вкладку.A plugins/<name> folder: plugin.py adds tools, panel.html adds a tab.

Как она думает

How she thinks

Два шага, чтобы характер не мешал делу: сначала сухой исполнитель с инструментами, потом ответ в вашем стиле.

Two steps so the personality doesn't get in the way of the work: a dry executor with tools first, then a reply in the style you chose.

Вы: «Напомни размяться через 30 минут»
You: “Remind me to stretch in 30 minutes”
→
Исполнитель: add_reminder, до 8 шагов
Executor: add_reminder, up to 8 steps
→
Черновик-факты: «22:10, размяться»
Fact draft: “22:10, stretch”
→
Стилизация: характер + память
Styling: personality + memory
→
Ответ голосом, эмоция на лице
Spoken reply, emotion on her face

Как росла

How it grew

По истории коммитов: 97 штук за три недели в git.

From the commit history: 97 commits in three weeks of git.

  1. 25.10.2026

    0.9.0 — первая сборка для людей— first public build

    Мастер первого запуска (имя, характер, «мозг»), уровень дружбы, «вебка» поверх игр, едет на окне, вздрагивает от грохота, дыхание 4-7-8, установщик и проверка в Windows Sandbox.

    First-run wizard (name, personality, brain), friendship level, a “webcam” over games, riding on windows, startles at loud noises, 4-7-8 breathing, installer tested in Windows Sandbox.

  2. 26.10.2026

    Открытый код и английскийOpen source and English

    Публичный репозиторий на GitHub, перевод интерфейса, картинки в чате через Ctrl+V.

    Public GitHub repo, translated UI, pasting pictures into chat with Ctrl+V.

  3. 03.11.2026

    0.9.1 — «Глаза» в Майнкрафте— “Eyes” in Minecraft

    Мод, через который она видит игру; живее в покое; офлайн-голос Kokoro для английского.

    A mod that lets her see the game; livelier when idle; offline Kokoro voice for English.

  4. 07.11.2026

    0.9.1.1 — починка голоса с эмоциями— emotional voice fix

  5. 14.11.2026

    Voice and hearing are picked in the wizard and install themselves, the chatter setting finally works, local models no longer drop out. Code license moves to AGPL-3.0.
